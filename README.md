# foreign 🇬🇧

**foreign** — небольшое веб-приложение для самостоятельного изучения английского языка русскоязычными учениками.

## Возможности

- Словарь из 20 базовых слов уровня A1
- Поиск по английским словам и русскому переводу
- Фильтр по категориям
- Карточки для повторения слов
- Мини-тест с четырьмя вариантами ответа
- Локальное сохранение изученных слов и правильных ответов в браузере
- Адаптивный интерфейс для компьютера и телефона

## Как запустить

Никаких зависимостей или сборки не требуется.

1. Скачай или клонируй репозиторий.
2. Открой файл `index.html` в браузере.

## Публикация через GitHub Pages

1. Открой репозиторий `foreign` на GitHub.
2. Перейди в **Settings → Pages**.
3. В разделе **Build and deployment** выбери **Deploy from a branch**.
4. Выбери ветку `main` и папку `/(root)`.
5. Нажми **Save** и подожди, пока GitHub Pages опубликует сайт.

Адрес сайта будет иметь вид `https://ТВОЙ-ЛОГИН.github.io/foreign/`.

## Структура проекта

- `index.html` — структура страниц и элементов интерфейса
- `style.css` — оформление и адаптация под мобильные устройства
- `app.js` — словарь, карточки, тест и сохранение прогресса

## Технологии

HTML · CSS · JavaScript · localStorage · GitHub Pages

## Важно

Прогресс сохраняется в локальном хранилище браузера на текущем устройстве. Это не облачная синхронизация между устройствами. Google Fonts подключается через интернет; системные шрифты обеспечивают запасной вариант.
